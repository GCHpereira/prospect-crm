# Screenshots

Espaço reservado para as capturas de tela do README. Use **somente dados fictícios**
(nunca leads reais, nomes de pessoas, telefones ou e-mails reais).

Sugestão de arquivos:

| Arquivo | Conteúdo |
|---|---|
| `desktop-painel.png` | Painel com os indicadores |
| `desktop-leads.png` | Lista de leads (cards e tabela) |
| `desktop-importar.png` | Importação com prévia |
| `mobile-leads.png` | Lista no celular |
| `mobile-lead.png` | Detalhe do lead com o botão de WhatsApp |

Como gerar dados fictícios: rode `npm run dev`, aplique `node scripts/migrate-local.mjs` e
importe uma planilha criada à mão a partir de `public/modelo-leads.csv` (nomes inventados,
telefones fictícios). Depois descomente as imagens no `README.md`.
